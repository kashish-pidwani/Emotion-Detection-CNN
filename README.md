# 🎭 Facial Emotion Detection using CNN

## 📌 Overview
This project builds a Convolutional Neural Network (CNN) to classify facial emotions from images. It demonstrates an end-to-end deep learning pipeline including preprocessing, training, evaluation, and explainability using Grad-CAM.

---

## 🚀 Features
- Image preprocessing (grayscale, resizing)
- CNN-based emotion classification
- Accuracy and loss visualization
- Confusion matrix analysis
- Grad-CAM for explainable AI
- Prediction on unseen real-world images

---

## 📊 Dataset
FER-2013 dataset  
https://www.kaggle.com/datasets/msambare/fer2013

---

## 📈 Results
- Validation Accuracy: ~43%
- Model performs well on clear expressions but struggles with subtle and neutral emotions

---

## 🔍 Observations
- Confusion between similar emotions (happy/neutral, sad/fear)
- Limited by low-resolution dataset
- Performance improves with clear facial features
